A 40-second vertical GTA 6 hype clip, cut by an AI agent from Rockstar's official Grand Theft Auto VI Trailer 2 — Lucia's prison kick, Vice City highway, the neon nightclub, Jason & Lucia on the run, and the May 26, 2026 date — ending with a make.fun pitch: this clip was cut by AI, and you can get paid to make clips like this.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) validates `VIDEO.json` — the public YouTube address of the clip — and writes `/output/VIDEO.json` + `/output/manifest.json`.
